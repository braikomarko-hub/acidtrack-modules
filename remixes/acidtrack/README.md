# acidtrack

aCiDtRacK, Marko Brajković's live set on the Octatrack MKI: OCTA303 (the OCTA-303 machine),
dEVILish (Devil Fish), DISTORX (SD-1 / RAT / Turbo RAT), dB666 (side-chain from any track),
USB (MIDI and AUDIO OUT MASTER) and BRAIN with REMIX SWITCH (other remixes' `.RMX`
images booted from the card without flashing); DARK REV is the one reverb. PLATE REV, SPRING REV, CHORUS,
PHASER and EQUALIZER are given up for the modules' DSP words (dB666 takes EQUALIZER's id).

Ran on the author's MKI as images ACIDV68..ACIDV71 (October 2026), built from the author's
older tree; on this tree `make check REMIX=acidtrack` is still to be run.

BRAIN and MEMORY were added on 20 Oct 2026 and have not yet run in this remix on the unit.
