# acidtrack

aCiDtRacK, Marko Brajković's live set on the Octatrack MKI: OCTA303 (the OCTA-303 machine),
dEVILish (Devil Fish), DISTORX (SD-1 / RAT / Turbo RAT), DBX 160 (side-chain from any track),
USB MIDI and USB AUDIO OUT (MASTER); DARK REV is the one reverb. PLATE REV, SPRING REV, CHORUS,
PHASER and EQUALIZER are given up for the modules' DSP words (DBX 160 takes EQUALIZER's id).

Ran on the author's MKI as images ACIDV68..ACIDV71 (October 2026), built from the author's
older tree; on this tree `make check REMIX=acidtrack` is still to be run.
